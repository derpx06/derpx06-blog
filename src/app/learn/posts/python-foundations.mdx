## Structural Basics

### Whitespace Formatting

"In other lands," Py continues, "they use curly braces `{}` to cage their code. Here, we use **whitespace** and **indentation**. It is elegant, but it demands respect."

<CodeBlock
    codes={[
        {
            code: `for i in [1, 2, 3, 4, 5]:
    print(i)                # We are inside the loop
    for j in [1, 2, 3, 4, 5]:
        print(j)            # Deeper still!
        print(i + j)
    print(i)                # Back to the outer level
print("done looping")       # We have emerged!`,
            language: "python",
            label: "whitespace.py"
        }
    ]}
    marginBottom="24"
/>

> [!WARNING]
> "Beware!" Py warns. "Whitespace is ignored inside parentheses `()`. Use this to your advantage when your spells (calculations) become too long for one line."
