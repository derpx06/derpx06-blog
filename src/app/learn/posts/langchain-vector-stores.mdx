# Vector Stores & Embeddings

One of the most common ways to store and search over unstructured data is to embed it and store the resulting embedding vectors. At query time, you embed the unstructured query and retrieve the embedding vectors that are 'most similar' to the embedded query. By default, this is done using Cosine Similarity.

## 1. Embeddings
An "embedding" is a dense vector of floating point numbers (e.g., `[0.1, -0.4, 0.8, ...]`).
-   The distance between two vectors measures their **semantic similarity**.
-   Similar texts have vectors that are close together.

## 2. Vector Stores
A Vector Store takes care of storing this embedded data and performing vector searches for you. Common adapters include:
-   **Chroma** (Open-source, local)
-   **FAISS** (Facebook AI Similarity Search, extremely fast, RAM-based)
-   **Pinecone / Weaviate / Qdrant** (Hosted / Production-grade)

from langchain.text_splitter import CharacterTextSplitter
from langchain.embeddings import OpenAIEmbeddings
from langchain.vectorstores import FAISS

# 1. Load Data
loader = TextLoader("state_of_the_union.txt")
documents = loader.load()

# 2. Split Data (Context Window Management)
text_splitter = CharacterTextSplitter(chunk_size=1000, chunk_overlap=0)
docs = text_splitter.split_documents(documents)

# 3. Create Embeddings & Store in Vector DB (FAISS)
embeddings = OpenAIEmbeddings()
db = FAISS.from_documents(docs, embeddings)

# 4. Semantic Search
query = "What did the president say about Ketanji Brown Jackson"
docs = db.similarity_search(query)

print(docs[0].page_content)`,
