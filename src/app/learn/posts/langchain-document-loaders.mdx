# Document Loaders

Before you can chat with your data, you need to load it. LangChain provides over 100 loaders for different file types and data sources.

## The `Document` Object
A loader returns a list of `Document` objects. A `Document` has two fields:
-   `page_content`: The string content.
-   `metadata`: A dictionary containing source info (e.g., source file path, page number).

## Common Loaders

### 1. TextLoader
The simplest loader. Reads a file from disk.

### 2. PyPDFLoader
Loads PDFs where each page is a separate document.

### 3. WebBaseLoader
Scrapes a webpage and cleans the HTML to text.
