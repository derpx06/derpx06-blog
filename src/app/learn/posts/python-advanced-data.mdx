# Advanced Data Tools

## Functional Programming

"Functions are not just actions," Py says mystically. "They are data. Pass them, return them, reshape them."

<CodeBlock
    codes={[
        {
            code: `from functools import partial

def exp(base, power):
    return base ** power

# Freeze the base to 2!
two_to_the = partial(exp, 2)
print(two_to_the(3))          # 8`,

## Generators

"Imagine a scroll that never ends," Py whispers. "A list takes up space. A **Generator** creates the path only as you walk it."

<CodeBlock
    codes={[
        {
            code: `def lazy_range(n):
    i = 0
    while i < n:
        yield i
        i += 1

# Consuming the infinite(ish)
for i in lazy_range(10):
    print(i)`,
            language: "python",
            label: "generators.py"
        }
    ]}
