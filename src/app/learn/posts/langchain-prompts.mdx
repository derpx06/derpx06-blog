# Prompts

Prompts are the input to the LLM. In LangChain, we treat prompts not just as strings, but as structured objects.

## Anatomy of a Prompt
A good prompt typically contains:
1.  **Instruction**: What you want the model to do.
2.  **Context**: Background information (RAG).
3.  **Input Data**: The specific question.
4.  **Output Indicator**: How you want the answer formatted.

## Prompt Templates
Hardcoding strings is bad practice. `PromptTemplate` allows you to create reusable recipes.
