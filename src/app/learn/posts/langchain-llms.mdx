# LLMs vs Chat Models

In LangChain, distinctions are made between two types of language models: **LLMs** and **Chat Models**. Understanding this difference is crucial for choosing the right interface for your application.

## 1. LLMs (Text Completion)
"LLMs" in LangChain refer to pure text completion models. The APIs take a string prompt and return a string completion.
-   **Input**: `str`
-   **Output**: `str`

Examples: `GPT-3 (Davinci)`, `Llama-2 Base`.

## 2. Chat Models (Messages)
Chat Models are usually backed by LLMs but are tuned for conversation using "ChatML" or similar schemas. They interface with a list of messages.
-   **Input**: `List[BaseMessage]`
-   **Output**: `BaseMessage`

Examples: `GPT-4`, `Claude 3`, `Llama-3 Instruct`.

### Message Types
-   **SystemMessage**: Context, instructions, or persona for the AI.
-   **HumanMessage**: Input from the user.
-   **AIMessage**: Response from the model.
