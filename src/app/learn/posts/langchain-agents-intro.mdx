# Introduction to Agents

In **Chains**, the sequence of actions is hardcoded. In **Agents**, a language model is used as a reasoning engine to determine which actions to take and in which order.

## The Agent Loop
1.  **Observation**: The agent looks at the user input and available tools.
2.  **Thought**: The LLM decides "I need to use the Search tool".
3.  **Action**: The tool is executed.
4.  **Observation**: The output of the tool is fed back to the LLM.
5.  **Answer**: If the LLM has enough info, it responds to the user.

## Agent Types
-   **Zero-shot ReAct**: The most general purpose agent. Uses the "Reasoning + Acting" framework.
-   **OpenAI Functions Agent**: optimized for models that support function calling (like GPT-3.5-turbo and GPT-4).
