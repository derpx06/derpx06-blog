# Working with Data

"The world is messy," Py warns. "Data is chaotic. We need tools to tame it."

## Iteration Utilities

"Never count manually properly," Py scoffs. "Let Python count for you with `enumerate` and `zip`."

<CodeBlock
    codes={[
        {
            code: `names = ["Alice", "Bob"]
ages = [25, 30]

# Enumerate: The Index Finder
for i, name in enumerate(names):
    print(f"{i}: {name}")

# Zip: The Weaver
for name, age in zip(names, ages):
    print(f"{name} is {age}")`,
            language: "python",
            label: "iteration.py"
        }
    ]}
