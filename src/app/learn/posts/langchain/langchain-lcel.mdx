# LangChain Expression Language (LCEL)

LCEL is a declarative way to compose chains. It was designed from day one to support **streaming**, **async**, and **batching** out of the box.

## The Pipe Operator `|`
LCEL uses the Unix pipe operator `|` to chain components. The output of one component becomes the input of the next.

`Chain = Prompt | Model | OutputParser`

## Why LCEL?
1.  **Streaming Support**: You get streaming of tokens for free.
2.  **Async Support**: Any chain can be run synchronously or asynchronously.
3.  **Parallel Execution**: Run steps in parallel transparently.

## Example: The LCEL Way

<CodeBlock

        {
            code: `from langchain.chat_models import ChatOpenAI
from langchain.prompts import ChatPromptTemplate
from langchain.schema.output_parser import StrOutputParser

model = ChatOpenAI()
prompt = ChatPromptTemplate.from_template("Tell me a joke about {topic}")
output_parser = StrOutputParser()

# The Magic of LCEL
chain = prompt | model | output_parser

# Invocation
response = chain.invoke({"topic": "Ice Cream"})
print(response)

# Streaming (Free!)
for chunk in chain.stream({"topic": "Ice Cream"}):
    print(chunk, end="", flush=True)`,

The `prompt | model | output_parser` syntax is significantly more readable and powerful than the legacy class-based approach.
