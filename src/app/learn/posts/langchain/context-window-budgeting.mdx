# Context Window Budgeting

Just like financial budgeting, you must allocate your tokens wisely. Reserve space for:
- System Prompt
- Few-Shot Examples
- Retrieved Context (RAG)
- User Query
- Answer Generation Buffer (Output tokens)

> **Important:** Most models have separate limits for Input (context) and Output (generation). You might have 128k input tokens but only be allowed to generate 4k tokens of output. Don't confuse the two!
