# Project: PDF Chat

In this project, we combine everything we've learned: Loaders, Splitters, Embeddings, Vector Stores, and Chains.

## The Architecture
1.  **Ingest**: Load PDF -> Split Text -> Embed -> Store in ChromaDB.
2.  **Retrieve**: User Question -> Embed -> Similarity Search.
3.  **Generate**: Retrieved Content + Question -> LLM -> Answer.
