# Text Splitters

LLMs have limited context windows. You cannot pass a 500-page book into a prompt. **Text Splitting** breaks documents into smaller, semantically meaningful chunks.

## RecursiveCharacterTextSplitter
This is the recommended splitter for generic text. It tries to keep looking for a logical place to split (paragraphs, then newlines, then spaces) to keep semantic chunks together.

### Parameters
-   `chunk_size`: The maximum number of characters (or tokens) in a chunk.
-   `chunk_overlap`: Crucial for keeping context between chunks (e.g., sliding window).
