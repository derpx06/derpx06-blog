# Prompting Essentials

Prompt engineering is the art of crafting inputs (prompts) to get the best possible output from an LLM. While it often feels like magic, there is a science to it.

## The Components of a Prompt

A prompt generally consists of four key elements:

1.  **Instruction**: Specific task you want the model to perform.
2.  **Context**: External information or additional context that limits the model's scope.
3.  **Input Data**: The input or question that we are interested in finding a response for.
4.  **Output Indicator**: The type or format of the output.

## Zero-Shot vs. Few-Shot

-   **Zero-Shot**: Asking the model to do something without any examples.
-   **Few-Shot**: Providing a set of examples (demonstrations) to help the model understand what you want.

Effective prompting is improved by clearly separating these components and iterating on the instruction.
