# Tools

A **Tool** is a function that an Agent can call. It consists of:
1.  **Name**: How the model refers to it.
2.  **Description**: Detailed instructions on *when* the model should use it.
3.  **Arguments**: The schema of inputs the tool accepts.

## The `@tool` Decorator
The easiest way to define a custom tool is using the `@tool` decorator.

## Code Example

<CodeBlock
    marginBottom="24"
    codes={[
        {
            code: `from langchain.tools import tool

@tool
def get_weather(location: str) -> str:
    """Returns the weather for a given location."""
    # Call real weather API here
    if "London" in location:
        return "Rainy, 15C"
    return "Sunny, 25C"

# View the schema automatically generated for the agent
print(get_weather.name)
print(get_weather.description)
print(get_weather.args)

# Execute
print(get_weather.invoke("London"))`,
