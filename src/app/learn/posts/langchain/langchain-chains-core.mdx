# Chains Basics

In LangChain, a **Chain** refers to a sequence of calls (to an LLM, a tool, or a data preprocessing step). It is the legacy abstraction for composing logic. The modern approach uses **LCEL** (LangChain Expression Language), but understanding the concept of a chain is still fundamental.

## Why Chains?
LLMs are powerful but often require multiple steps to produce a desired output.
-   **Prompt formatting**: Injecting user input into a template.
-   **Model inference**: Getting the completion.
-   **Output parsing**: Converting the string back into structured data.

## Legacy `LLMChain`
Historically, `LLMChain` was the primary entry point.
